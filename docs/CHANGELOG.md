## Unreleased

## v1.2.1 - 2026-11-21

- Remove the stutter in both directions. Five independent causes, each measured
  on the board and on the server:
  - the downlink was limited by the terminal's receive queues, not the link —
    `TCP_RECVMBOX_SIZE` 6, `TCP_OOSEQ_MAX_PBUFS` 4 and `RX_BA_WIN` 6 were what
    filled first, not the TCP window; the device now receives 49 KB/s with the
    same client-visible rate as a reference client on the same Wi-Fi;
  - playback started from an empty ring, so every network gap starved the DMA —
    it now pre-buffers 160 ms and re-buffers after 200 ms dry;
  - the server's `max pump stall` fell from 5791 ms to 3 ms;
  - the uplink ran with Nagle and a four-MSS send buffer: 31% of audio sends
    blocked over 30 ms, worst 89 ms. `tools/patch_ws_nodelay.sh` sets
    TCP_NODELAY and `TCP_SND_BUF_DEFAULT` doubles; sends now block at most
    9–17 ms and the server reports `queue_drops=0` on every session;
  - transmit audio was clipping 5% of samples because the device's analog PGA
    (+30 dB) and the server's software gain (+12 dB) stacked. The software gain
    was an identity operation with a headroom cost; at 0 dB a full transmission
    adds zero clipped samples.
  See [transport tuning](transport-tuning.md) for the measurements.

- Make the firmware gate work again. `tools/verify_firmware.py` still demanded an
  image called `FoloToy-AI-Passport.bin` after the project was renamed to
  `mrrc-terminal`, so every firmware check — and with it every tag release since
  1.0.0 — failed with `flash_args is missing required images`. The application
  image is now derived from `flash_args`, and `tools/archive_firmware.py` does the
  same.

- Every Markdown file now has an English default and a `.zh_CN` peer as the
  repository rule requires; `./tools/validate.sh --static` exits 0 for the first
  time, with the host tests reported as skipped because this fork does not vendor
  the upstream `tests/` tree.

## v1.2.0 - 2026-11-20

- Releases are source-only from now on: the tag workflow still builds and verifies the image as a gate, but it publishes no firmware artifact, and the GitHub Release carries only the automatically attached source archives. A CI image cannot hold this terminal's credentials, so a prebuilt image would boot and never reach the radio.

- Stop losing downlink audio frames: the 8 KB PCM ring becomes 16 KB (0.26 s -> 0.51 s) so the TCP backlog at session start has somewhere to land, the WebSocket receive buffer goes 4 KB -> 8 KB so a 1701-byte spectrum frame no longer back-pressures the socket (the server measured a 5.8 s pump stall), and the link is now half duplex — the spectrum tier drops to `low` and scope frames are discarded while keyed. Measured on the live server by the author: `err=0 drop=0` at 49.9 frames/s. On our bench unit the same build still loses ~2%, so a second cause remains open.

- Add `probe/`, the throwaway bring-up firmware for the next-generation touch handheld (ILI9341 + FT6336G + ES8311), with its design document. It is a separate ESP-IDF project under `probe/` and is not part of the `mrrc-terminal` image.

- Make a clean checkout build and fit on the board: restore `CONFIG_LV_FONT_MONTSERRAT_44` (the frequency readout uses that face and `sdkconfig.defaults` no longer enabled it, so a fresh clone did not compile), turn off `CONFIG_LV_ATTRIBUTE_FAST_MEM_USE_IRAM` (with the `^9.5.0` constraint resolving to LVGL 9.6 it moved ~117 KB of code into SRAM, leaving an 88 KB boot heap and an `esp_wifi_init` out-of-memory reboot loop), and split the defaults so per-device credentials live in a gitignored `sdkconfig.defaults.local` instead of the public tree.

- Added the supplied 80-byte CW2017 profile for the specified 520 mAh cell, including content/update-flag checks, verified writes, the required restart sequence, and bounded SOC-readiness polling.

- Expanded the environment bootstrap document: added Espressif's Git service mirror (`git.espressif.com.cn`) as the preferred mainland-China route for ESP-IDF v5.5.3 and its submodules, documented submodule long-wait/timeout handling, in-place repair, and the pinned-commit shallow fetch for large submodules such as `esp32-wifi-lib`, warned about stale per-repository Jihulab `insteadOf` residue, and added the official offline release archive as a last-resort fallback (learned from `esp-mosaico/esp-mosaico-vibe`).

Removed `docs/software-design/` (empty scaffold); folded the three `assets/{fonts,images,music}/README` leaves into the `assets/` README; flattened the six `project-completion` sub-documents into a single file; and unified each directory to a single README, eliminating every `INDEX` file and a duplicated experience index.
