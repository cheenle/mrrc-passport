# 现场速查卡

一页纸，打印出来贴在机器背面。这里每个数字都同时出现在 `SDD/` 里——有测试核对这一点，
所以这张卡不会悄悄变成某个错误数值的唯一存放处。

## 1. 这次发射健康吗？

看 `tx done:` 那一行，六项必须**在同一次运行里**全部成立：

| 字段 | 要求 | 参考运行（2026-11-22） |
| --- | --- | --- |
| `frames` | ≈50 × 秒数 | 30.5 秒内 1500 帧 = 50.0/s |
| `sendfail` | 0 | 0 |
| `readfail` | 0 | 0 |
| `peak` | 20 000–29 000 | MIC 30 dB 时 27 522 |
| `send_max` | 移动 ≤50 ms，局域网 ≤17 ms | 移动链路 27.9 ms，`slow=0` |
| 窗口内 W/E 日志行 | 0 | 0 |

`sendfail` 高但**没有** W/E 行 → 上行是被下层掐住了。
`sendfail` 高**且有** W/E 行 → 会话在死，PTT 灯只是症状，不是故障本身。

## 2. 症状 → 第一台仪器

| 症状 | 先读 | 然后 |
| --- | --- | --- |
| 音频卡顿、`drop` 上升 | 先 `mem:` 再 `link:` | **不要**先加大缓冲 |
| 按着键 TX 灯灭 | 先 `tx done:` 再看 W/E | 出现 W/E 行就是 socket 的事 |
| 没声音、显示正常 | `i2s …/s` | 区分环饿死与下行静默 |
| 完全没反应、面板黑 | `mem:` 启动阶段 | 最后一个是哪一步 `mem_report` |
| 连不上服务器 | `ws: total=`、IPv6 地址 | 三个 IPv6 开关（§4） |
| 上机声音小、`peak` 低 | 发射行 `peak` | 提高 PGA 档位，绝不用服务器增益 |

## 3. 电平：在 ADC 处，不在软件里

- 目标 `peak` **20 000–29 000**（满量程 32767）。
- 本机 MIC **30 dB** 实测 **27 522**（84%）；MIC **36 dB** 实测 **32 768**
  ——在 ADC 处就削波了，任何软件之前。
- 服务器的 `tx_mic_db` 保持 **0**。放到 +3 dB 时削波从 5.0% 升到 5.8%：
  天花板从来不是服务器能修的。

## 4. 网络

- **三件事**同时成立，否则接口永远显示 `0 IPv6`：`CONFIG_LWIP_IPV6=y`、
  `CONFIG_LWIP_IPV6_AUTOCONFIG=y`，以及 `GOT_IP` 之后调用
  `esp_netif_create_ip6_linklocal(netif)`。
- 开机优先**上次可用**的网络；切换需要持续的音频劣化，不是 RSSI 低——
  一个 **−25 dBm** 的 AP 实测在丢 10% 的包。
- 加入失败后重试 **30 秒**，再失败就转 SoftAP。
- 配网：连 `MRRC-Passport-XXXX`，打开 `http://192.168.4.1`，填表单。
  预算：+80 KB flash，运行期间约 15 KB 堆。

## 5. 不许做

| 不许 | 因为 |
| --- | --- |
| 没读 `mem:`/`link:` 就加大缓冲 | 两轮这么干过，什么都没改变 |
| 加软件 TX 增益 | 它只是重缩放已量化的样本；天花板在 ADC |
| 运行期调 `bsp_audio_set_format` | 会删除并重建编解码器：爆音加几十毫秒断流 |
| 发滤波**频率**而不是索引 | Hz 由服务器派生；索引是 13→2400、17→2700、20→3000 |
| 丢掉 WS 帧的通道字节 | `0x00`/`0x01`/`0x02` 就是整个协议 |
| 在出货构建里开 `CONFIG_MRRC_PROFILE=y` | 它会改变它正在测的东西 |

## 6. 打开仪器

```
idf.py menuconfig → MRRC Terminal → Profile diagnostics (CONFIG_MRRC_PROFILE=y)
```

之后每分钟：`mem:`、`tx:`、`i2s`、`drop`；按需：`link:`、`ws:`、`txlink:`、
`ring()`、`batt=`。每次发射：`tx done:`。

设备上**没有持久日志**。一次现场故障留下的证据，就是当时有人在看的那条串口行——
这就是为什么这些计数器被设计成"没有历史也够用"。

## 7. 推理在哪里

`SDD/00`（结论该怎么写）· `SDD/05`（数字）· `SDD/08`（为什么）· `SDD/12`（时序）·
`SDD/15`（发射安全）· `docs/transport-tuning.md`（传输事故）·
`docs/optimization-notes.md`（代价账本）。
