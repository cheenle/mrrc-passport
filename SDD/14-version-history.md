# 14. Version History

Newest first. This is an **evidence ledger**, not a changelog: the user-facing
release notes are in `../docs/CHANGELOG.md`, and they deliberately do not contain
hypotheses, dead ends or counter numbers. Each row here does, because the useful
part of a fix is the part that shows what other explanations were eliminated.

Row shape (chapter `00` §V4): **symptom → what was believed → what the measurement
showed → root cause (file:function) → fix → measured result → boundary, i.e. what
was *not* done.**

## What this ledger is not

- **Not a release history.** Tags, user-visible features and upgrade notes live in
  `../docs/CHANGELOG.md`; this table would be a bad changelog and a good changelog
  makes a bad ledger.
- **Not complete.** Rows exist for rounds that produced a measurement worth not
  re-deriving. An unremarkable change does not get a row, and the absence of a row
  is not evidence that nothing happened.
- **Not editable in place.** A wrong row is corrected by appending to it with the
  new date and the measurement that superseded it (chapter `00` §V4); the old
  number stays visible, because the fact that we once believed it is part of the
  record.
