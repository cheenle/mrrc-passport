# 03. 项目定义（ENG 343）

## 3.1 项目属性

| 属性 | 值 |
| --- | --- |
| 产品 | MRRC 终端 —— 手持业余无线电操作台 |
| 硬件 | FoloToy AI Passport（ESP32-C3 rev v1.1，160 MHz 单核，400 KB SRAM，8 MB flash，240×320 ST7789，ES8311） |
| 基线 | `ref/ai-passport` 的 fork；`components/bsp/` 与 `docs/` 大部分来自上游，应用层是本仓的 |
| 操作系统 | ESP-IDF v5.5.3（FreeRTOS，单核） |
| 对端 | `mrrc_modern` 服务器 `w103d.vlsc.net:8888`，单条 `/WSterminal` 会话 |
| 发布方式 | 仅源码。CI 会构建并校验镜像，但不发布 BIN：镜像无法携带凭证，刷机的人必须用自己的配置编译 |
| 本记录的拥有范围 | 固件侧：编解码器、缓冲、任务、显示、配网、发射路径的设备端 |

## 3.2 范围内

- 接收：单条 `/WSterminal` 会话、PCM16 下行、经共享 I2S 时钟播放、跨网络空档的播放连续性。
- 发射：按键处理、20 ms PCM16 上行、电平控制、释放语义。
- 显示：频率、模式、S 表、频谱轨迹、瀑布、chips 栏、电量；240×320 面板无 framebuffer，5.26 Hz 节拍。
- 设置：旋钮（六档）、滤波宽度索引、步进、麦克风增益、扬声器音量，持久化在 NVS。
- 连接：三个 Wi-Fi 网络、开机选择、按健康度切换、无任何基础设施的 SoftAP 配网。
- 可观测性：每分钟一条 idle 行、每次发射一行、`CONFIG_MRRC_PROFILE` 诊断构建。

## 3.3 范围外

- 服务器。会话策略、按键仲裁、下行抑制、RX/TX 增益都在 `mrrc_modern`，那是那个仓库的决策；
  本固件只记录它依赖了什么（第 `08` 章 AD-004）。
- 电台。CAT 命令、滤波宽度索引之外的行为、电台自己的 TOT，属于服务器与硬件。
- 压缩。没有 Opus 路径，加一条等于重新审判 AD-002，而不是一个功能。
- 多设备仲裁。两条终端共用一个服务器会话是服务器的问题；固件假设自己可能在会话中途被替换，
  且必须能挺过"被要求停止发射"。
- 录音、FT8、SDR 收听：服务器功能，终端没有对应界面。

## 3.4 成功判据

每一条都是设备所处的某种状态，用点名的仪器验证（第 `00` 章 §0.3）。验不了的判据不写进来。

| ID | 判据 | 验证 |
| --- | --- | --- |
| SC1 | 上电后不用任何人工操作就到达可用会话 | 串口时间线：关联 → 登录 → `/WSterminal` 建立 → 首帧可听，全部在一次预缓冲内 |
| SC2 | 持续会话中接收不中断 | `link:` 行：`underruns` ≤2/s，`rebuf` 在 ≥10 分钟内不增长 |
| SC3 | 一次完整发射能撑住 | `tx done:` 行：50 帧/秒、`sendfail=0`、窗口内 W/E 日志行 0 条 |
| SC4 | 显示不说谎 | 只画真实频谱帧（插值出的扫描不得计入数据）、5.26 Hz 节拍、无 `task_wdt` |
| SC5 | 内存永不跌破握手底线 | `mem:` 行：`largest` 稳态 ≥24 KB，任何时候 ≥16 KB |
| SC6 | 没有网络的设备仍能被配网 | SoftAP + 手机，无路由器，不重新编译 |
| SC7 | 换网络不会把终端变砖 | 三个已配网络；开机选到能用的；链路劣化时按音频健康度切换 |
| SC8 | 现场故障能靠一条串口行诊断 | 第 `00` 章 §0.3：不用调试器即可区分链路/设备/服务器 |
| SC9 | 凭证永不外泄 | 全树 guardian 规则 `secrets-in-tracked-config`；CI 在没有 `sdkconfig.defaults.local` 下构建 |
| SC10 | 源码能在别处可复现地构建 | 干净检出上 `./tools/validate.sh --all`（ESP-IDF 5.5.3），guardian 自测全绿 |

## 3.6 什么情况下这个项目算失败

写下来，是为了上面那张判据表不被读成一张没有方向感的清单：

- 瀑布显示合成出来的扫描，却宣称自己是瀑布；
- 终端在拥塞链路上发射时直接死掉，而不是丢一帧；
- 一台只能用串口线救回来的设备；
- 一个把电平问题"修"成削波的响度修复，因为电平从来不是服务器能修的；
- 记录里的数字没人能复现。
